# audits/

**Historical/raw analysis.**

Place read-only audit reports, codebase investigations, and verification findings
here. These are inputs to the workflow — evidence to be reviewed, not authority.

## Naming

- `AUDIT-<shortname>.md` — a read-only audit by the Desktop AI
- `ANALYSIS-<shortname>.md` — a structured analysis (see `workflow/ANALYZE.md`)
- `VERIFY-<shortname>.md` — verification of an external claim (see `workflow/VERIFY.md`)

## Conventions

- Every file must state its date, author role (Web AI / Desktop AI / Human), and
  the verdict/confidence conventions used.
- Findings that survive verification should be mirrored into
  `../ISSUE_REGISTER.md`.
- Nothing here is authoritative on its own — it is evidence.
