# TamashaRoom (تماشاروم) — Product Brief

**What it is**: A synchronized watch-party platform for Persian-speaking users. 
Create a private room, share an invite link, and watch an external video together — 
play, pause, seek, and position stay in sync for everyone in the room.

**Users**: Persian-speaking friends/families who want to watch movies or shows 
together while physically apart. Casual, social, warm — not a professional 
streaming/enterprise product.

**Mode**: Mixed — the landing page should Persuade (make people want to try it), 
the in-room experience should Operate (get out of the way, let the video and chat 
be the focus — sync status, controls, and presence need to be scannable at a glance, 
not decorative).

**Brand voice**: Warm, intimate, a little nostalgic — the feeling of watching a 
movie on the couch with friends, not a corporate SaaS tool. Avoid anything that 
reads as "startup dashboard."

**Language & direction**: Persian (Farsi) is the primary language. The entire UI 
is RTL (right-to-left) — this is not optional and not a secondary locale. Typography, 
icon direction, spacing, and layout must be designed RTL-first, not LTR-then-mirrored. 
Use a proper Persian-supporting typeface for body/UI text (e.g. Vazirmatn, 
IRANSans-family, or similar variable Persian webfont) paired with a distinctive 
display face for headings.

**Anti-references**: purple-to-pink gradient heroes, Inter-as-everything, generic 
"AI SaaS" nav (logo-left/links-center/CTA-right/sticky), icon-tile feature grids, 
centered-everything layouts, fabricated stats/testimonials, glassmorphism as a 
default rather than a deliberate choice.

**Tech context**: Laravel 13 + Inertia.js + React 19 + TypeScript + Tailwind CSS 4. 
Design work should produce Tailwind-based components that fit this stack, not raw 
inline CSS.

**Design system**: See DESIGN.md for the full visual system (colors, typography, numeral rules, calendar system) — this document covers brand/product direction only.
